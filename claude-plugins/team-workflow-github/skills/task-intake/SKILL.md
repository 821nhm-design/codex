# 依頼をIssueにまとめる

対象リポジトリは特に指定がなければ `821nhm-design/codex`。

## 手順

1. 依頼内容から次の項目を読み取る。足りない項目は推測で埋めず、ユーザーに1回でまとめて質問する。
   - タイトル（何をするか、20〜40文字）
   - 目的（なぜやるか）
   - 完成の条件（何ができたら終わりか、箇条書き）
   - 期限（あれば）
   - 種類ラベル：`サイト制作` / `楽曲制作` / `デジタル商品` / `海外販売` / `その他`
2. 既存Issueを検索し、同じ内容のものがないか確認する。似たIssueがあれば作成せず、そのリンクを示して「追記しますか？」と聞く。
3. 下書きを次の形でチャットに表示する。

   ```
   タイトル: …
   ラベル: …
   ---
   ## 目的
   …
   ## 完成の条件
   - [ ] …
   ## 期限
   …
   ## 参考
   …
   ```

4. ユーザーが「OK」「作って」と明確に答えてから Issue を作成する。作成後はIssueの番号とリンクを1行で伝える。

## 守ること

- 本文に個人情報（住所・電話番号・メールアドレス・決済情報・パスワード）を書かない。依頼文に含まれていたら伏せて「〔個人情報のため省略〕」と書き、その旨を伝える。
- 価格・公開日・決済設定は、ユーザーが決めた値だけを書く。Claudeが提案した値は「案」と明記する。
- ラベルが存在しない場合は勝手に作らず、ラベルなしで作るか確認する。
